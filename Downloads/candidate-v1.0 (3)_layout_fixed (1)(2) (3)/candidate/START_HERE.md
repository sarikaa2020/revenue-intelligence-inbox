## Separate Growth Associate assignment

This package also includes a separate College Event Planning and Review assignment. It is intended for Growth Associate candidates and does not change the Revenue Intelligence Inbox exercise. Open `growth_associate/College_Event_Assignment.pdf` or `growth_associate/COLLEGE_EVENT_ASSIGNMENT.md`.


Open index.html in a browser for the complete offline reading pack, or read Assignment.pdf.

1. Read ASSIGNMENT.md for the product challenge and scope.
2. Read DATA_DICTIONARY.md for field meanings and glossary.
3. Follow DATA_CONTRACT.md for identity, revisions, replay and exports.
4. Import data/01_initial.json. Use data/02_update.json for the announced late-transcript test.
5. Read CONVERSATIONS.md or the HTML conversation library. The reader contains the final text from both deliveries; the application must still honour the initial/update sequence. The reader is a convenience, not a second data source.
6. Use SUBMISSION_CHECKLIST.md when submitting.

The package includes 44 distinct source records and 18 adapted real-derived conversations. Seventeen texts are available initially and the last arrives in the update. Two source files do not mean two complete snapshots.

The data is de-identified and adapted; it is not a verbatim export. The nested source field structure is retained. Share the assignment privately and do not publish source datasets publicly. AI tools are allowed for the exercise.
